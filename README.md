O Alphaz TV+ é um site de fã (fan site) dedicado a reunir, organizar e divulgar o trabalho do grupo musical japonês XG. A plataforma centraliza conteúdos multimídia com foco em uma experiência imersiva para a comunidade de fãs (Alphaz).
O projeto foi totalmente desenvolvido pensando na responsividade, garantindo uma navegação fluida e adaptada para computadores, tablets e smartphones.

Acesse: https://www.alphaztvplus.com.br/

## Features

- **Integração com YouTube** - Sincronização e exibição de conteúdos oficiais do grupo.
- **Player Embutido (Embed)** - Visualização de vídeos diretamente dentro da plataforma.
- **Galeria de Fotos** - Carrossel de fotos de ensaios fotograficos da banda e de cada membro.
- **Suporte Multi-idioma (i18n)** - Tradução completa e suporte para Português, Inglês e Espanhol.
- **Design Responsivo**: Interface otimizada para qualquer tamanho de tela (PC, Tablet e Mobile).

## Requisitos

- **React** (v19.1.0)
- **Vite** (v7.0.4)
- **Axios** (v1.12.1)

## Instalação

1. Instale as dependencias

```bash
yarn install
```

2. Inicie o servidor:

```bash
yarn dev
```

3. Abra o aplicativo:
  - Abra o endereço gerado no terminal (geralmente http://localhost:5173).
